CivicEye — AI-Powered Civic PlatformCivicEye is an AI-powered civic issue detection, prioritization, and routing platform designed for smart city infrastructure. It enables citizens to report urban problems (such as potholes, garbage piles, broken streetlights, damaged roads, overflowing bins, and illegal dumping), automatically analyzes reports using computer vision, clusters duplicate complaints, calculates a transparent $0-100$ priority score, routes tasks to municipal departments, tracks authority resolutions, and empowers citizens to verify fixes.This repository provides a complete full-stack implementation with a Node.js & Express backend, secure authentication (JWT + bcrypt), persistent file storage, and a React frontend SPA.🚀 Key FeaturesAI Computer Vision Analysis: Integrates the Google Gemini API (@google/genai) with an offline YOLOv8 fallback predictor to automatically classify defects, confidence percentages, bounding boxes, and severity ratings.Smart GIS Duplicate Detection: Uses spatial proximity clustering via the Haversine formula (150m radius) to merge multiple citizen reports of the same issue into a single master record, preventing administrative clutter.Transparent Priority Engine: Evaluates issues using a weighted multi-factor formula:$$\text{Priority} = (\text{Severity} \times 30\%) + (\text{Reports} \times 20\%) + (\text{Traffic} \times 20\%) + (\text{Location Risk} \times 15\%) + (\text{Time Unresolved} \times 15\%)$$Department Auto-Routing: Automatically routes reported problems to specialized municipal boards (e.g., Public Works, Sanitation, Electrical Board).Secure Authentication & RBAC: Features bcrypt password hashing (10 rounds) and JSON Web Token (JWT) authorization guards enforcing strict role-based access control for citizen, authority, and admin roles.Citizen Verification Workflow: Allows citizens to confirm resolved issues to close them or dispute incomplete work to reopen cases.🛠️ Architecture & Tech StackFrontend: React 19, Vite, Tailwind CSS, Lucide IconsBackend: Node.js, Express, TypeScript, tsxDatabase & Persistence: Structured JSON persistent database file
