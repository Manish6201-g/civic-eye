👁️ CivicEye — AI-Powered Civic PlatformCivicEye is a full-stack smart city platform that automates civic issue detection, prioritization, and routing. It uses AI computer vision to analyze citizen reports, clusters duplicates via GIS spatial proximity, calculates transparent priority scores, and routes tasks to municipal departments.🚀 Key FeaturesAI Computer Vision: Uses the Google Gemini API (@google/genai) and an offline YOLOv8 fallback to classify urban defects, confidence, and severity.Smart GIS Clustering: Merges duplicate reports within a 150m Haversine radius to reduce administrative clutter.Transparent Priority Engine: Scores issues (0–100) using weighted factors (Severity, Report Count, Traffic, Location Risk, and Age).Automated Department Routing: Directs issues to relevant boards (e.g., Public Works, Sanitation, Electrical).Role-Based Access Control (RBAC): Secure JWT & bcrypt authentication supporting Citizen, Authority, and Admin roles.Verification Workflow: Enables citizens to verify fixes or dispute incomplete work.🛠️ Tech Stack & ArchitectureFrontend: React 19, Vite, Tailwind CSS, Lucide IconsBackend: Node.js, Express, TypeScript, tsxDatabase: Structured JSON persistent storage (/data/civiceye_db.json)AI & Security: @google/genai, jsonwebtoken, bcryptjs🔐 Demo AccountsRoleEmailPasswordDepartmentCitizencitizen@civiceye.govCitizen123!Public CitizenAuthorityauthority@civiceye.govAuthority123!Dept. of Public Works & RoadsAdminadmin@civiceye.govAdmin123!Municipal Oversight
